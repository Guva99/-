# Auros — landing page

Одностраничный лендинг в стиле **Auros: abyssal terminal with bioluminescent data orbs** —
тёмно-бирюзовое полотно, биолюминесцентная сфера частиц, рационированная палитра
и типографика с агрессивным отрицательным трекингом.

Статика без сборки и зависимостей: откройте `index.html` или поднимите любой статический сервер.

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000
```

## Структура

```
index.html         разметка страницы
assets/styles.css  дизайн-токены и все стили
assets/main.js     сфера частиц, счётчики, reveal-анимации, навигация
```

## Дизайн-система

Все токены объявлены в `:root` внутри `assets/styles.css`.

| Слой | Токен | Значение |
|------|-------|----------|
| Canvas | `--surface-liquid-abyss` | `#012624` |
| Recessed | `--surface-liquid-deep` | `#011d1c` |
| Raised card | `--surface-liquid-kelp` | `#003734` |
| Text primary | `--color-platinum` | `#ffffff` |
| Text body | `--color-silver-mist` | `#bbc7c6` |
| Text emphasis | `--color-liquid-mist` | `#edfffe` |
| Stats accent | `--color-lavender-phosphor` | `#fde9ff` |
| CTA | `--gradient-aurora-gradient` | cyan → white → pink |

Правила системы, которых придерживается разметка:

- глубина передаётся сдвигом поверхностей в бирюзовом стеке, **без теней**;
- заголовки — только вес 500, никакого bold/light;
- радиусы только двух значений: карточки `16px`, мелкие элементы и кнопки `6px`;
- аврора-градиент используется только на первичных CTA;
- lavender-phosphor — только для крупных цифр статистики;
- uppercase-лейблы с трекингом `0.08–0.15em`;
- line-height `1.0` для дисплейного текста и `1.4` для body.

Шрифт Matter проприетарный, поэтому подключён Inter как ближайший
геометрический гротеск-субститут (`--font-matter` содержит обе гарнитуры).

## Секции

1. **Hero** — сфера частиц на canvas, eyebrow → заголовок → подзаголовок → CTA.
2. **Stats** — три метрики с анимированными счётчиками.
3. **Approach** — кинетическая бегущая строка + текстовый блок.
4. **Explore** — асимметричные две колонки: карточки направлений и молекулярная графика.
5. **Capabilities** — три surface-карточки на `#003734`.
6. **Insights** — pull-quote.
7. **CTA** — recessed-панель с формой (валидация на клиенте, без бэкенда).
8. **Footer** — утопленный уровень `#011d1c`.

## Поведение

- Сфера частиц: распределение Фибоначчи, перспективная проекция, параллакс от курсора;
  рендер останавливается, когда hero уходит из вьюпорта или вкладка скрыта.
- `prefers-reduced-motion` отключает анимации: сфера рисуется одним статичным кадром,
  счётчики показывают финальные значения, reveal и марки-строка выключены.
- Адаптив: 1024px — колонки схлопываются, 760px — бургер-меню и одноколоночная сетка.
