# Частицы — фигуры по скроллу

Страница без контента: только фоновое поле из контурных треугольников,
которое пересобирается в узнаваемые фигуры при прокрутке.

Статика без сборки и зависимостей: откройте `index.html` или поднимите любой статический сервер.

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000
```

## Структура

```
index.html         канвас и шесть пустых экранов с data-formation
assets/styles.css  белый холст, fixed-канвас, размеры слотов
assets/main.js     система частиц и формации
```

## Как это работает

Один `position: fixed` канвас на весь экран, 5200 контурных треугольников
(2000 на мобильных). Размеры от 1.5px до 70px по кривой `pow(r, 5.6)` — мелкая
«пыль» с редкими крупными бледными фигурами. Палитра: серые `#E8E8E8` / `#BFBFBF`
/ `#7B7B7B` и оранжевые `#FD622C` / `#FC5922` / `#C24A22` / `#FFDBCE`.

Позиция каждой частицы — чистая функция прокрутки: поле **перетекает** из
фигуры в фигуру, а не пересобирается заново. Страница делится на экраны с
атрибутом `data-formation`; на каждом кадре берутся две соседние фигуры и доля
пути между ними, и частица линейно интерполируется между своими целями в них.
Пока экран близко к центру, фигура держится; перетек занимает среднюю треть пути
(`ease()` со smoothstep).

| Экран | Фигура |
|-------|--------|
| 1 | хаос: сгустки со смещением плотности вправо |
| 2 | лампочка |
| 3 | планета: вращающийся шар с материками |
| 4 | растущие столбцы со стрелкой вверх |
| 5 | облако реплики с кавычками |
| 6 | конверт |

Цели каждой фигуры считаются один раз и сортируются по углу вокруг центроида,
поэтому частица занимает одно и то же угловое место во всех фигурах — переход
читается как согласованное течение, а не как случайное перемешивание.

**Планета** — единственная фигура, которая живёт во времени: точки лежат на
сфере, каждый кадр вращаются вокруг наклонённой оси и проецируются в
перспективе, задняя полусфера гаснет. Оборот занимает около 52 секунд.
Материки заданы набором эллипсов в градусах широты и долготы с рваным краем
(`isLand()`), на сушу ложится 76% частиц, ещё 12% держат неподвижный лимб —
без чёткого края шар на белом фоне не читается.

Мозг задан процедурно, но сейчас на странице не показан — чтобы вернуть его,
достаточно поставить `data-formation="brain"` на любой экран.

Остальные фигуры рисуются обычными командами канваса
в офскрин-буфер 220×220, после чего непрозрачные пиксели становятся целями для
частиц — см. `rasterise()` в `assets/main.js`. Чтобы добавить свою фигуру,
достаточно дописать функцию рисования в объект `SHAPES` и повесить
`data-formation` на новый экран.

Каждый экран содержит пустой квадрат `.figure-slot`; поле каждый кадр берёт из
него центр и масштаб, поэтому фигура собирается ровно в нём и подстраивается
под размер устройства.

Положение и наклон задаются в разметке:

- классы `stage-left` / `stage-right` — фигура уходит в левую или правую
  половину страницы (на экранах уже 720px остаётся по центру, иначе была бы
  слишком мелкой);
- `data-rotate` — поворот в градусах вокруг центроида фигуры, отрицательное
  значение вращает против часовой стрелки;
- `data-scale` — множитель размера; вместе с фигурой пропорционально растут и
  сами треугольники, чтобы контур не редел. Размер ограничен высотой экрана,
  поэтому фигура не обрезается на невысоких окнах.

У лампочки: `stage-right`, `data-rotate="-30"`, `data-scale="2"`.

## Производительность

Кадр собирается в бакеты «цвет × квантованная альфа × толщина линии» — не больше
84 вызовов `stroke()` вместо 2800. Фигуры за пределами вьюпорта отсекаются,
рендер останавливается, когда вкладка скрыта.

`prefers-reduced-motion` выключает анимацию: поле рисуется одним статичным кадром.
