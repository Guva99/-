# Частицы — фигуры по скроллу

Страница без контента: только фоновое поле из контурных треугольников,
которое пересобирается в узнаваемые фигуры при прокрутке.

Статика без сборки и зависимостей: откройте `index.html` или поднимите любой статический сервер.

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000
```

## Структура

```
index.html         канвас и шесть пустых экранов с data-formation
assets/styles.css  белый холст, fixed-канвас, размеры слотов
assets/main.js     система частиц и формации
```

## Как это работает

Один `position: fixed` канвас на весь экран, 2800 контурных треугольников
(1100 на мобильных). Размеры от 1.5px до 70px по кривой `pow(r, 5.6)` — мелкая
«пыль» с редкими крупными бледными фигурами. Палитра: серые `#E8E8E8` / `#BFBFBF`
/ `#7B7B7B` и оранжевые `#FD622C` / `#FC5922` / `#C24A22` / `#FFDBCE`.

Активная формация выбирается по близости секции к центру вьюпорта
(атрибут `data-formation`), частицы плавно интерполируются к новым целям:

| Экран | Фигура |
|-------|--------|
| 1 | хаос: сгустки со смещением плотности вправо |
| 2 | лампочка |
| 3 | мозг: бугристый контур, межполушарная щель, борозда мозжечка, извилины |
| 4 | растущие столбцы со стрелкой вверх |
| 5 | облако реплики с кавычками |
| 6 | конверт |

Мозг задан процедурно. Остальные фигуры рисуются обычными командами канваса
в офскрин-буфер 220×220, после чего непрозрачные пиксели становятся целями для
частиц — см. `rasterise()` в `assets/main.js`. Чтобы добавить свою фигуру,
достаточно дописать функцию рисования в объект `SHAPES` и повесить
`data-formation` на новый экран.

Каждый экран содержит пустой квадрат `.figure-slot`; поле каждый кадр берёт из
него центр и масштаб, поэтому фигура всегда собирается в центре экрана и
подстраивается под размер устройства.

## Производительность

Кадр собирается в бакеты «цвет × квантованная альфа × толщина линии» — не больше
84 вызовов `stroke()` вместо 2800. Фигуры за пределами вьюпорта отсекаются,
рендер останавливается, когда вкладка скрыта.

`prefers-reduced-motion` выключает анимацию: поле рисуется одним статичным кадром.
